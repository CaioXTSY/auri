## 💡 Como Usar Esta Estrutura

### Para Escrever o TCC

1. **Leitura Sequencial**: Siga a ordem das pastas (01 → 10)
2. **Capítulos do TCC**: Cada pasta = 1 capítulo principal
3. **Subseções**: Cada arquivo .md = 1 subseção ou tópico

### Para Desenvolvimento

1. **Requisitos** → Implementação
2. **Arquitetura** → Setup técnico
3. **Módulos** → Desenvolvimento por sprint

### Para Apresentação

1. Use arquivos como base para slides
2. Destaque: `01-introducao.md`, `03-justificativa.md`, `08-etica/01-uso-etico-ia.md`
3. Demo: use descrições de `05-modulos/`
