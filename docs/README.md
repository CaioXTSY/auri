# 📚 Documentação do TCC - Plataforma Gamificada de Ensino de Programação

## 🎯 Visão Geral

Este projeto consiste em uma plataforma web gamificada para apoio ao ensino de programação, integrando elementos de gamificação, gestão de disciplinas, e uso controlado de Inteligência Artificial como ferramenta auxiliar ao professor.
